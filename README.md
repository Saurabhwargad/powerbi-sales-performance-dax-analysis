# Sales Performance Analysis - Power BI (DAX)

## Project Overview
This dashboard demonstrates advanced DAX calculations to evaluate sales performance and profitability. The analysis focuses on order trends, product-level profit contribution, and customer insights.

## Key Metrics
- Total Orders: 100
- Total Profit: ₹6,16,50,562.50
- Total Quantity: 2,858
- Profit Cost: 21,575

## DAX Measures Implemented
- Total Profit
- Unique Order Count
- Profit Margin %
- Average Order Value (AOV)
- Monthly Aggregations
- Cost vs Profit Comparison

## Analysis Highlights
- Top profitable product: Dhokla
- Highest order month: March
- Customer-wise quantity contribution analysis
- Monthly and daily order distribution

## Tools Used
- Power BI
- DAX (Data Analysis Expressions)
- Data Modeling

## Objective
To demonstrate analytical thinking and DAX proficiency in business intelligence reporting.
